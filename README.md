# 視覺化期末報告製作完整指南

> 本文件說明如何利用目前已準備好的素材，完成「打炒房與升息雙重壓力下，北北房價區域落差不減反增？」這份視覺化期末報告。

---

## 1. 題目與核心論點

**主標題**  
打炒房與升息雙重壓力下，北北房價區域落差不減反增？實價登錄揭露蛋黃區 vs 蛋白區的真實差距

**副標題**  
2015–2025 行政區單價中位數變化與分位數差距分析

**核心論點**  
2022 年升息循環啟動後，蛋黃區（市中心精華區）與蛋白區（外圍區）的房價差距不減反增，反而有擴大現象。

**最大優勢（一定要強調）**
- 蛋黃區定義使用 **2015-2017 基期預先固定**，嚴格避免事後 cherry-picking（確認偏誤）。
- 完全不使用經緯度，降低資料處理風險。

## 3. 建議報告架構（推薦順序）

以下架構已對照你原本的評分標準與手冊建議：

1. **封面 / 首頁**
   - 主標題 + 副標題
   - **放入 fig1_timeseries.png**（最大的一張圖）

2. **問題意識（1 頁）**
   - 打炒房 + 升息的雙重政策背景
   - 為什麼要看「蛋黃 vs 蛋白」的差距？

3. **報導架構 / 方法論（1 頁）**
   - 表格呈現研究設計
   - **重點強調**：蛋黃區定義預先固定（2015-2017 基期）

4. **資料運用（1 頁）**
   - 資料來源：內政部實價登錄
   - 蛋黃區定義流程圖
   - 引用 `egg_yolk_definition.json`

5. **結果分析（3–5 頁）** ← 核心
   - **第 1 張**：fig1_timeseries.png + 新聞式圖說
   - **第 2 張**：fig3_before_after.png（政策前後對比）
   - **第 3 張**：fig2_gap.png（差距擴大趨勢）
   - 搭配 ACH 競爭假設討論

6. **結論與反思（1–2 頁）**
   - 4–5 點 bullet（參考 REPORT_HANDOFF.md）
   - 誠實披露限制

7. **附錄 / 互動式報表**
   - 放 `interactive_housing_report.html` 連結或截圖
   - 說明這是用來探索的工具

8. **個人心得 + infographic（1 頁）**
   - 重點寫「預先固定分類」如何避免確認偏誤

## 4. 各素材使用建議

### 靜態圖（一定要放進報告/PPT）
- **fig1_timeseries.png**：最強的主圖，強烈建議放第一張。
- **fig3_before_after.png**：適合做政策前後對比，圖說容易寫。
- **fig2_gap.png**：當佐證差距確實擴大的證據。

### 互動式報表
- 用途：教授問「有做互動嗎？」時的加分項目。
- 可以放在附錄，或做成可點擊的連結。
- 優點：可以讓教授自己勾選不同行政區看走勢。

### REPORT_HANDOFF.md
- 這是你最重要的參考文件。
- 裡面有 ACH 5 個競爭假設、每張圖的建議圖說、資料品質披露文字。

---

## 5. 建議製作步驟（時間順序）

1. **先把靜態圖看懂**
   - 打開三張 PNG，思考每張圖要傳達什麼故事。

2. **寫結果章節（最花時間）**
   - 先寫 fig1 的圖說 + 分析。
   - 再搭配 ACH 假設討論。

3. **補前面的問題意識與方法**
   - 強調「預先固定」這件事。

4. **做 PPT**
   - 建議每頁 1 張大圖 + 1 句結論。
   - 互動式報表可以放在最後 demo。

5. **寫個人心得 + infographic**
   - 建議主題：「預先分類 vs 事後挑選」。

6. **自評報告**
   - 濃縮成 1 頁，附上 1–2 張關鍵圖。
